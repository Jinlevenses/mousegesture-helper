# Button4 + wheel paging

- 목적: 버튼4를 누른 채 휠을 돌려 문서를 페이지 단위로 이동.
- 선택한 방식: 버튼4 + 휠. 버튼3 + 휠은 기존 클릭, 홀드, 드래그와 겹치므로 이번 범위에서 제외.
- 버튼을 누르지 않았을 때와 같은 스크롤 진행 방향으로 Page Up/Down을 전송. macOS 자연스러운 스크롤 설정을 그대로 반영.
- 버튼4 단독 클릭은 기존 클릭으로 전달. 휠을 사용한 뒤 버튼4를 놓을 때 단독 클릭을 추가로 보내지 않음.
- 버튼3 제스처와 버튼5 동작은 유지.
- 버튼4를 누르지 않은 일반 휠은 이벤트를 수정하지 않고 통과. 트랙패드의 연속 스크롤과 수평 휠도 통과.
- 구현: 현재 설치된 Karabiner-Elements 16.1을 유지. 별도 선택 규칙으로 button4를 F19 down/up과 단독 button4 클릭으로 변환하고, helper는 F19가 눌린 동안 수직 휠을 Page Up/Down으로 변환.
- 대안: Karabiner의 wheel-to-key 기능은 16.3.9부터 제공되므로 현재 버전에서는 사용할 수 없음. 이 기능 때문에 Karabiner 전체를 업데이트하지 않음.
- 검증: F19/F20 소비, 단독 클릭 규칙, 위/아래 방향, 자연스러운 스크롤 양쪽 설정, 일반 휠 통과, 연속/수평 스크롤 통과, 버튼을 놓은 뒤 원래 스크롤 복원.
- 사용자가 확인한 방향 문제는 일반 휠과 버튼4 페이지 이동 사이의 방향 불일치. 입력에 이미 반영된 자연스러운 스크롤 방향을 다시 반전하지 않음.
